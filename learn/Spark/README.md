# Spark Learning Notes

This folder is currently a placeholder for distributed data-processing examples.

## What Spark Will Be For In This Repository

- Large-scale data preprocessing
- Distributed feature engineering
- Batch inference pipelines
- ML workflows that no longer fit on a single machine

## When To Study This

Do not start here if your goal is first-principles ML understanding.

Study Spark after:

1. You understand the core ML algorithms in `learn/Supervised/` and `learn/Unsupervised/`
2. You are comfortable with pandas and NumPy workflows on a single machine
3. You need to reason about scale, partitions, shuffles, and distributed execution

For concrete Spark-oriented examples in this repository, look at the production-style folders under `Use_Cases/`.
